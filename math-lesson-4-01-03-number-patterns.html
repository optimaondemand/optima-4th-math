Today's Mission
Use what you know about place value to find the rule behind a number pattern — then extend it. When a number grows by the same amount every step, only some of the digits change.
❓
Essential Question
When a number grows by a steady amount, which digits change — and which ones stay still?

If you start at 27,400 and add 1,000 every step, what part of the number actually moves? What part stays the same?

The place-value chart can tell you the answer before you do any of the work.

Pattern Extender: Week by Week
The rule is +1,000. Step through three more weeks.

Here are the first three weeks of attendance from your warm-up. The rule is +1,000. Tap Step Forward three times to fill in Weeks 4, 5, and 6. Watch which digit changes each time.

Rule: +1,000
You filled in the whole pattern. Week 4: 30,400. Week 5: 31,400. Week 6: 32,400. The thousands digit ticked up by 1 each step: 7 → 8 → 9 → 30 (carried) → 31 → 32. Every other digit stayed exactly the same.
📐 What You Just Saw

The rule lives in one place at a time. When the rule is "add 1,000," the thousands digit is the one doing the work. Hundreds, tens, and ones don't move at all.

But pay attention to Week 4. The number went from 29,400 to 30,400. Two digits changed that time — the 9 in thousands became 0, and the 2 in ten-thousands became 3. That is what happens when a place hits 10: it carries one to the place on its left, just like place value taught you. The rule is still "+1,000." It always was.

🔗 The Place That Changes

Here's the rule in one table. Each row starts from 24,536 and adds a different amount. Watch which digit ticks up.

Rule Start Next Which Digit Changed?
+10 24,536 24,546 Tens (3 → 4)
+100 24,536 24,636 Hundreds (5 → 6)
+1,000 24,536 25,536 Thousands (4 → 5)
+10,000 24,536 34,536 Ten-thousands (2 → 3)

The match is exact. Add 10 → the tens digit moves. Add 100 → the hundreds digit moves. The rule and the place name say the same thing.

Worked Example: Season Ticket Sales
Find the rule. Predict five weeks out.
Problem

The team sells season tickets in batches each Monday. Week 1: 12,300 sold. Week 2: 14,300. Week 3: 16,300. (a) What is the rule? (b) How many tickets will be sold by Week 5? (c) Which place-value digit is doing the changing?

Watch how the Math Crew works through this one:

A
Atlas — concrete
"I line up the numbers vertically. 12,300 / 14,300 / 16,300. The thousands digit goes 2 → 4 → 6. Steady jump of 2,000."
H
Hazel — pictorial
"I draw an arrow between Week 1 and Week 2 and label it +2,000. Then I check the next arrow — also +2,000. Same rule both times."

12,300 → 14,300 → 16,300 → 18,300 → 20,300

F
Felix — shortcut
"Subtract: 14,300 − 12,300 = 2,000. The rule is +2,000. To find Week 5, I add 2,000 four times — or jump straight: 12,300 + 4×2,000 = 12,300 + 8,000 = 20,300."
C
Cora — checking
"Week 5 should be 20,300. Watch what happened from Week 4 to Week 5: 18,300 → 20,300. Two digits changed! The 8 in thousands hit 10, so it carried up. That's how patterns cross over."
⚠️

About that carry: When the thousands digit hits 10, it rolls over to 0 and adds 1 to ten-thousands. From 18,300 + 2,000, we'd get "110,300" — but that's not how numbers work, so the 10 thousands become 1 ten-thousand. 18,300 + 2,000 = 20,300. The rule is still +2,000; the chart just had to do extra work.

Run It Backward
Patterns go both ways.

The team also tracks who turned in tickets back — like for refunds or transfers. The pattern shrinks instead of growing. Two students described the same backward pattern in different ways.

STUDENT A — Subtraction Rule
"The rule is −500. So 8,400 → 7,900 → 7,400 → 6,900."
STUDENT B — Reverse a Forward Pattern
"It's a +500 pattern read in reverse. 6,900 → 7,400 → 7,900 → 8,400, just played backward."
🧐

Both students get the same four numbers. Student A names the rule directly (subtract). Student B uses what they already know about adding and runs the list backward. Both work — they're different ways to think about the same pattern.

✏️ Which strategy would you use first if a pattern was shrinking? Why? Use 8,400 → 7,900 → 7,400 to explain how the hundreds digit moves.
