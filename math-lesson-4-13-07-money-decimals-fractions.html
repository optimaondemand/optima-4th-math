✅ Total $4.15, change $0.85.
Add: pennies 5 + 0 = 5, dimes 7 + 4 = 11 (trade 10 dimes for a dollar), dollars 0 + 3 + 1 = 4. Total $4.15. Change: $5.00 − $4.15 = $0.85. Count up to check: $4.15 + 5¢ = $4.20, + 80¢ = $5.00. That’s 85¢. ✓

📐 What You Just Saw

Money is a decimal. Dollars are ones. Dimes are tenths. Pennies (cents) are hundredths.

So one amount has three names: $3.75 = 375¢ = 3 75100 dollars.

Add and subtract money the same way you add and subtract any decimals: line up the decimal points, start with the hundredths, and regroup when you need to.

Step 1. $3.75 + $2.48: pennies 13 (trade), dimes 12 (trade), dollars 6. Total $6.23.
Step 2. $10.00 − $6.23: break a dollar into dimes, and a dime into pennies. Left: $3.77.
Three names. $3.77 = 377¢ = 3 77100 dollars.
Check by counting up. $6.23 + 7¢ = $6.30. + 70¢ = $7.00. + $3 = $10.00. 7¢ + 70¢ + $3 = $3.77. ✓
