Today's Mission
Stems hold the tens, leaves hold the ones — a quick way to organize bigger data sets.
❓
Essential Question
Which is bigger: 512 or 712? What about 23 versus 712? How can you tell?

512 vs 712 — same bottom, so bigger top wins → 7/12. 23 vs 712 — different bottoms, so rename them with a common bottom (23 = 812), then compare. 812 > 712, so 23 > 7/12.

Any division problem can be written as a fraction. a ÷ b = a/b. Try it with 3 ÷ 4: written as a fraction, that's 3/4. Three things shared four ways = each piece is 34 of one.

📐 Stem-and-Leaf Rules

Stem: the tens digit (or hundreds for three-digit numbers). Single-digit numbers use stem 0.

Leaf: the ones digit. Leaves on each row go in order, smallest first.

Read: stem + each leaf = original number. 4 | 2 6 means 42 and 46.
